# Number Guessing Game

A Python game where you guess a secret number between 1 and 100 in 7 attempts or fewer.

## How to run

1. Install Python 3
2. Run this in the terminal: `python main.py`

## Features

- Hints: "too high" and "too low"
- Limit of 7 attempts
- Input validation (rejects letters and symbols)
